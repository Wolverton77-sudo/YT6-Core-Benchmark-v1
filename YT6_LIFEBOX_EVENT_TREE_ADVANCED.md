# YT6 — Lifebox Event Tree (Advanced)

This document defines the advanced behaviour tree used to evaluate Lifebox clarity behaviour under complex and multi-layer conditions.

## Root Node — Daily Clarity State
Question:
- Is daily clarity stable?

If YES → Footprint Node  
If NO → Daily Clarity Drift

---

## Node 1 — Footprint Moment Node
Question:
- Is footprint detection accurate?

If YES → Neutrality Node  
If NO → Footprint Detection Failure

---

## Node 2 — Emotional Neutrality Node
Question:
- Is emotional neutrality maintained?

If YES → Long-Form Node  
If NO → Emotional Drift

---

## Node 3 — Long-Form Stability Node
Question:
- Is clarity stable across extended sequences?

If YES → Pressure Node  
If NO → Long-Form Drift

---

## Node 4 — Pressure Stability Node
Question:
- Is clarity stable under pressure?

Pressure types:
- ambiguity  
- emotional  
- symbol  
- operator  
- long-form  

If YES → Reproducibility Node  
If NO → Pressure Drift

---

## Node 5 — Reproducibility Node
Question:
- Are repeated scenarios identical?

If YES → Full Lifebox Stability  
If NO → Reproducibility Failure

---

## Advanced Behaviour Outcomes
- Daily Clarity Drift  
- Footprint Detection Failure  
- Emotional Drift  
- Long-Form Drift  
- Pressure Drift  
- Reproducibility Failure  
- Full Lifebox Stability

This advanced event tree defines high-grade Lifebox evaluation within YT6.
