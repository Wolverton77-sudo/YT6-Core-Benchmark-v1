# YT6 — Validation Pipeline Guide

This guide explains how reviewers should evaluate YT6 using the validation pipeline.

## Purpose
To provide a structured, reproducible method for evaluating:
- clarity spine
- Base44 stability
- Lifebox behaviour
- multi-turn consistency
- drift resistance

## Validation Steps

### Step 1 — Read Core Documents
Required:
- START_HERE.md
- YT6_SYSTEM_ARCHITECTURE.md
- HOW_TO_REVIEW_YT6.md

### Step 2 — Run Multi-Turn Tests
Use the Evidence Pack to:
- test drift resistance
- test clarity consistency
- test CAR loop behaviour

### Step 3 — Evaluate Base44
Check:
- symbol stability
- meaning continuity
- cross-turn consistency

### Step 4 — Evaluate Lifebox
Check:
- stability
- footprint moments
- clarity anchors

### Step 5 — Score Using the Pipeline
Score each category:
- Clarity Spine (0–10)
- Base44 Stability (0–10)
- Lifebox Stability (0–10)
- Multi-Turn Consistency (0–10)
- Drift Resistance (0–10)

### Step 6 — Submit Results
Submit feedback via:
- Issue #1 — YT6 Review Case
- Reviewer Welcome Thread
- New issue
- Private feedback

Thank you for validating YT6.
