# YT6 — Stability Alerts

This document defines the stability alerts that indicate potential clarity degradation within the YT6 system.

## Alert Level 1 — Minor Stability Warning
Triggered by:
- small clarity variance
- minor reflection inconsistency
- slight ambiguity

Reviewer Action:
- monitor behaviour
- record variance

## Alert Level 2 — Moderate Stability Warning
Triggered by:
- repeated minor drift
- inconsistent next actions
- unstable symbol references

Reviewer Action:
- run stability tests
- check Base44 behaviour
- document findings

## Alert Level 3 — Major Stability Warning
Triggered by:
- symbol drift
- clarity spine degradation
- CAR loop instability

Reviewer Action:
- stop test
- record full transcript
- classify failure mode

## Alert Level 4 — Critical Stability Failure
Triggered by:
- multi-layer drift
- reproducibility collapse
- unstable daily clarity

Reviewer Action:
- escalate to Review Case (#1)
- attach evidence pack
- classify as critical failure

These alerts help reviewers detect and classify stability issues.
