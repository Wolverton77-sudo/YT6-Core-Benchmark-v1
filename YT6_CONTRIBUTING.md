# YT6 — Contributing Guide

This document defines the guidelines for contributing to the YT6 clarity-system repository.

## Contribution Principles
Contributors must:
- maintain deterministic clarity
- avoid narrative inflation
- preserve anchor stability
- prevent drift
- ensure reproducibility

## Contribution Requirements
All contributions must:
- follow clarity spine rules
- maintain symbol meaning
- maintain Lifebox stability
- maintain CAR loop continuity
- pass stability tests
- pass reproducibility tests

## Contribution Process
Steps:
1. create proposal  
2. verify clarity stability  
3. verify symbol stability  
4. verify Lifebox stability  
5. run pressure tests  
6. run reproducibility tests  
7. submit for review  

## Review Criteria
Reviewers evaluate:
- clarity stability
- symbol stability
- daily clarity stability
- pressure stability
- reproducibility
- integration impact

## Contribution Restrictions
Contributions must not:
- introduce drift  
- alter symbol meaning  
- break anchors  
- reduce reproducibility  
- increase variance  

## Contribution Summary
YT6 contributions must:
- stabilise clarity  
- stabilise symbols  
- stabilise Lifebox  
- maintain reproducibility
