# YT6 — Reviewer Expectation Guide

This document explains what reviewers should expect when evaluating the YT6 clarity-system.

## What Reviewers Should Expect

### 1. Clear Documentation
Reviewers will find:
- structured files
- clarity-first explanations
- reproducible evidence
- stable definitions

### 2. Predictable System Behaviour
YT6 maintains:
- stable clarity
- stable symbols
- stable CAR loop
- stable multi-turn behaviour

### 3. Anti-Drift Performance
Reviewers should observe:
- no narrative drift
- no meaning drift
- no symbol drift
- no emotional drift

### 4. Operator Discipline
YT> and yt3>= commands produce:
- literal execution
- operator-grade clarity
- deterministic output

### 5. Evidence Availability
Reviewers have access to:
- stability tests
- drift resistance tests
- cross-model tests
- reproducibility benchmarks

### 6. Structured Review Flow
Reviewers follow:
- START_HERE.md
- architecture files
- evidence pack
- validation pipeline
- scoring guide

### 7. Transparent Scoring
Reviewers use:
- 0–10 stability metrics
- structured scoring categories
- reproducible evaluation criteria

## Reviewer Responsibilities
Reviewers must:
- follow the review flow
- run evidence tests
- score using the pipeline
- submit structured feedback

This guide sets expectations for all YT6 reviewers.
