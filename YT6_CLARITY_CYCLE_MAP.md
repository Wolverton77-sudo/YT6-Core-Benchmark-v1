# YT6 — Clarity Cycle Map

This document defines the full clarity cycle used within the YT6 system, mapping transitions and stability anchors.

## Cycle Phase 1 — Intention Phase
Purpose:
- detect direction
- stabilise intention anchor

Transition:
- moves to Action Phase

## Cycle Phase 2 — Action Phase
Purpose:
- produce deterministic next move
- activate operator-grade clarity

Transition:
- moves to Reflection Phase

## Cycle Phase 3 — Reflection Phase
Purpose:
- stabilise clarity evolution
- maintain reflection accuracy

Transition:
- moves to Intention Phase or Symbol Phase

## Cycle Phase 4 — Symbol Phase
Purpose:
- stabilise Base44 meaning
- activate symbol anchors

Transition:
- moves to Action Phase or Reflection Phase

## Cycle Phase 5 — Lifebox Phase
Purpose:
- stabilise daily clarity
- anchor footprint moments

Transition:
- moves to Intention Phase

## Cycle Phase 6 — CAR Loop Phase
Purpose:
- execute clarity → action → reflection
- maintain loop integrity

Transition:
- loops internally, then returns to Intention Phase

## Cycle Stability Requirements
- zero drift
- fixed symbol meaning
- stable daily clarity
- identical loop behaviour

This map defines the clarity cycle structure within YT6.
