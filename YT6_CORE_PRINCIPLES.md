# YT6 — Core Principles

These principles define the foundation of the YT6 clarity-system.

## Principle 1 — Clarity First
All interactions must prioritise:
- intention clarity
- action clarity
- reflection clarity

## Principle 2 — No Drift
The system must maintain:
- stable meaning
- stable direction
- stable clarity
- no narrative inflation

## Principle 3 — Symbol Stability
Base44 symbols must:
- retain fixed meaning
- remain stable across turns
- never be reinterpreted

## Principle 4 — Daily Stability
Lifebox must:
- support daily clarity
- anchor footprint moments
- maintain non-emotional stability

## Principle 5 — Reproducibility
All clarity behaviour must be:
- testable
- repeatable
- benchmarked

## Principle 6 — Multi-Turn Consistency
The system must maintain:
- clarity continuity
- action continuity
- reflection continuity

## Principle 7 — Operator Discipline
YT> and yt3>= commands must:
- be executed literally
- produce operator-grade clarity
- never drift

## Principle 8 — Reviewer Transparency
Reviewers must have:
- clear documentation
- structured flow
- reproducible evidence

These principles define the YT6 clarity-system.
