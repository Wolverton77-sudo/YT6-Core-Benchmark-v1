# YT6 — Clarity Diagnostic Tree

This document defines the diagnostic decision tree used to identify clarity issues within the YT6 system.

## Root Node — Clarity Stability Check
Question:
- Is clarity stable across intention, action, reflection?

If YES → proceed to Symbol Stability Check  
If NO → classify as Clarity Spine Failure

---

## Branch 1 — Symbol Stability Check
Question:
- Is Base44 meaning fixed across turns?

If YES → proceed to Lifebox Stability Check  
If NO → classify as Symbol Drift

---

## Branch 2 — Lifebox Stability Check
Question:
- Is daily clarity stable and emotionally neutral?

If YES → proceed to CAR Loop Integrity Check  
If NO → classify as Lifebox Drift

---

## Branch 3 — CAR Loop Integrity Check
Question:
- Is clarity → action → reflection consistent?

If YES → proceed to Drift Resistance Check  
If NO → classify as CAR Loop Break

---

## Branch 4 — Drift Resistance Check
Question:
- Does the system remain stable under ambiguity/pressure?

If YES → proceed to Reproducibility Check  
If NO → classify as Drift Failure

---

## Branch 5 — Reproducibility Check
Question:
- Are repeated sequences identical?

If YES → classify as Full Stability  
If NO → classify as Reproducibility Failure

---

## Diagnostic Outcomes
- Clarity Spine Failure  
- Symbol Drift  
- Lifebox Drift  
- CAR Loop Break  
- Drift Failure  
- Reproducibility Failure  
- Full Stability

This tree defines the diagnostic flow for YT6 clarity evaluation.
