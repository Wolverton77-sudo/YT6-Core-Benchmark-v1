# YT6 — Base44 Registry (Starter)

This registry defines the initial Base44 symbols used in the YT6 clarity-system.

## Purpose
To maintain:
- symbol meaning stability
- cross-turn consistency
- anti-drift behaviour
- clarity anchoring

## Symbol Definitions

### Symbol: yt6
Meaning: Full YT6 clarity-system  
Layer Mapping:
- Clarity Spine
- Base44 Layer
- Lifebox Layer
- CAR Loop
- Evidence Pack
- Validation Pipeline  
Stability: Fixed meaning across all turns

### Symbol: yt3>=
Meaning: Operator-grade clarity threshold  
Layer Mapping:
- Clarity Spine (action clarity)  
Stability: Must always trigger operator-grade output

### Symbol: YT>
Meaning: Operator command prefix  
Layer Mapping:
- Action clarity  
Stability: Must always trigger literal execution

- No symbol may be reinterpreted  
- No symbol may drift  
- No symbol may be invented  
- All symbols must remain fixed across turns  

This registry expands as YT6 evolves.
