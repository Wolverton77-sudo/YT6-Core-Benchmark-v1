This document provides advanced guidance for reviewers evaluating complex or long-form YT6 behaviour.

- analyse intention evolution
- analyse action-chain correctness
- analyse reflection accuracy
- detect micro-drift patterns

## Section 2 — Symbolic Behaviour Analysis
Reviewers must:
- inspect symbol meaning under pressure
- inspect symbol meaning across long sequences
- detect symbol reinterpretation attempts

## Section 3 — Lifebox Behaviour Analysis
Reviewers must:
- analyse stability anchors
- analyse footprint moment handling
- analyse emotional neutrality under stress

## Section 4 — CAR Loop Integrity
Reviewers must:
- inspect loop continuity
- detect loop breaks
- confirm deterministic loop behaviour

## Section 5 — Drift Pattern Classification
Reviewers must classify:
- micro-drift
- macro-drift
- symbol drift
- reflection drift
- action drift

## Section 6 — Reproducibility Stress Testing
Reviewers must:
- run extended repeated-sequence tests
- compare outputs across sessions
- detect subtle clarity variance

## Section 7 — External Model Behaviour

- evaluate cross-model stability
- confirm Base44 portability
- confirm CAR loop portability
