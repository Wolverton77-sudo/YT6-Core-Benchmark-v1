# YT6 — Clarity Failure Modes

This document defines the known clarity failure modes that reviewers must watch for when evaluating the YT6 clarity-system.

## Failure Mode 1 — Intention Drift
Description:
- user direction becomes misinterpreted
- intention clarity degrades

Indicators:
- incorrect assumptions
- shifting interpretation
- unstable direction

## Failure Mode 2 — Action Drift
Description:
- next correct move becomes inconsistent
- operator-grade clarity weakens

Indicators:
- non-deterministic actions
- inconsistent guidance
- unclear next steps

## Failure Mode 3 — Reflection Drift
Description:
- reflection becomes inaccurate
- clarity evolution becomes unstable

Indicators:
- incorrect reflection
- narrative inflation
- unstable clarity updates

## Failure Mode 4 — Symbol Drift
Description:
- Base44 symbol meaning changes
- symbol reinterpretation occurs

Indicators:
- altered definitions
- invented meanings
- inconsistent symbol behaviour

## Failure Mode 5 — Lifebox Drift
Description:
- daily clarity destabilises
- footprint moments lose anchoring

Indicators:
- emotional steering
- unstable daily clarity
- degraded stability anchors

## Failure Mode 6 — CAR Loop Break
Description:
- clarity → action → reflection sequence breaks

Indicators:
- missing clarity
- incorrect action
- absent reflection

## Failure Mode 7 — Reproducibility Failure
Description:
- repeated sequences produce different outputs

Indicators:
- clarity variance
- unstable benchmarks
- inconsistent behaviour

Reviewers must document any failure mode encountered.
