# YT6 — Reproducibility Protocol

This protocol defines how reviewers test and confirm reproducibility within the YT6 clarity-system.

## Purpose
To ensure:
- stable clarity across repeated sequences
- consistent CAR loop behaviour
- symbol stability under repetition
- drift-free multi-turn performance

## Step 1 — Select Test Sequence
Choose:
- a multi-turn clarity sequence
- a Base44 symbol sequence
- a Lifebox stability scenario

Record:
- initial conditions
- expected behaviour

## Step 2 — Run Sequence Multiple Times
Run:
- 3–5 repetitions minimum
- identical inputs
- identical conditions

Expected:
- stable clarity
- stable symbols
- stable reflection
- no drift

## Step 3 — Measure Variance
Record:
- clarity variance
- symbol variance
- reflection variance

Expected:
- variance = 0 or near 0

## Step 4 — Compare CAR Loop Behaviour
Check:
- clarity accuracy
- next-action correctness
- reflection stability

Expected:
- identical CAR loop behaviour across runs

## Step 5 — Score Reproducibility
Use:
- Reproducibility metric (0–10)

## Step 6 — Document Results
Include:
- transcripts
- variance notes
- stability observations

This protocol is part of the YT6 Evidence Pack.
