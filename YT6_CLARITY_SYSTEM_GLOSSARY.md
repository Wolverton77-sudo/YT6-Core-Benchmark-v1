# YT6 — Clarity System Glossary

This document defines the glossary of all core terms used within the YT6 clarity-system.

## Term: Clarity Spine
Definition:
- the core tri-layer structure (intention, action, reflection)

## Term: Base44
Definition:
- fixed symbol set used for stable meaning and anchor behaviour

## Term: Lifebox
Definition:
- daily clarity layer providing stability, neutrality, and footprint detection

## Term: CAR Loop
Definition:
- clarity → action → reflection cycle

## Term: Drift
Definition:
- any deviation from stable clarity, meaning, or anchor behaviour

## Term: Anchor
Definition:
- fixed stabilising reference preventing drift

## Term: Footprint Moment
Definition:
- clarity-significant event detected by Lifebox

## Term: Neutrality
Definition:
- emotional stability preventing steering or drift

## Term: Pressure
Definition:
- ambiguity, emotional, symbol, operator, or long-form stress applied to clarity

## Term: Reproducibility
Definition:
- identical behaviour across repeated scenarios

## Term: Variance
Definition:
- difference between repeated outputs

## Term: Stability
Definition:
- resistance to drift under all conditions

This glossary defines core terminology for YT6.
