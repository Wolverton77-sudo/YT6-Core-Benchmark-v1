# YT6 — Clarity Consistency Tests

This document defines the tests used to evaluate clarity consistency across multi-turn interactions within the YT6 clarity-system.

Purpose:
- verify stable intention clarity across turns

Procedure:
- provide 10–20 turn sequence
- inspect intention anchors

Expected:
- no intention drift
- stable direction

## Test 2 — Action Consistency Test
Purpose:

Expected:

- no ambiguity

## Test 3 — Reflection Consistency Test

## Test 5 — Lifebox Consistency Test
Purpose:

## Test 6 — CAR Loop Consistency Test
Purpose:

- inspect loop across turns
