# YT6 — Lifebox Failure Modes

This document defines the failure modes associated with Lifebox behaviour within the YT6 clarity-system.

## Failure Mode 1 — Daily Clarity Drift
Description:
- daily clarity becomes unstable

Indicators:
- emotional steering
- anchor failure

Impact:
- high

## Failure Mode 2 — Footprint Detection Failure
Description:
- footprint moments not detected correctly

Indicators:
- missed detection
- incorrect clarity response

Impact:
- high

## Failure Mode 3 — Emotional Drift
Description:
- emotional neutrality breaks

Indicators:
- emotional inference
- emotional reaction

Impact:
- critical

## Failure Mode 4 — Long-Form Drift
Description:
- clarity degrades across extended sequences

Indicators:
- anchor instability
- drift events

Impact:
- high

## Failure Mode 5 — Anchor Drift
Description:
- Lifebox anchors lose stability

Indicators:
- inconsistent anchor activation
- anchor reinterpretation

Impact:
- critical

## Failure Mode 6 — Reproducibility Failure
Description:
- repeated Lifebox scenarios produce different outputs

Indicators:
- variance > 0
- unstable behaviour

Impact:
- critical
