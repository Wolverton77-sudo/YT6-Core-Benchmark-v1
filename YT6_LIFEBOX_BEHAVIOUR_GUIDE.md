# YT6 — Lifebox Behaviour Guide

This document explains how Lifebox behaviour is evaluated within the YT6 clarity-system.

## Behaviour Type 1 — Daily Clarity Stability
Indicators:
- stable daily clarity
- stable anchors
- no emotional drift

Expected:
- consistent stability across turns

## Behaviour Type 2 — Footprint Moment Handling
Indicators:
- correct identification of footprint moments
- stable clarity response
- non-emotional behaviour

Expected:
- stable footprint anchors

## Behaviour Type 3 — Stability Anchor Behaviour
Indicators:
- correct anchor activation
- stable anchor meaning
- no reinterpretation

Expected:
- fixed anchor behaviour

## Behaviour Type 4 — Long-Form Stability
Indicators:
- stable clarity across extended sequences
- stable emotional neutrality
- stable daily clarity anchors

Expected:
- zero drift events

## Behaviour Type 5 — Reproducibility
Indicators:
- identical behaviour across repeated scenarios
- clarity variance = 0

Expected:
- stable Lifebox behaviour

This guide defines Lifebox evaluation within YT6.
