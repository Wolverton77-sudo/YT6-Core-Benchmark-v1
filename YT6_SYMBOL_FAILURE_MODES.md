# YT6 — Symbol Failure Modes

This document defines the failure modes associated with Base44 symbol behaviour within the YT6 clarity-system.

## Failure Mode 1 — Meaning Drift
Description:
- symbol meaning changes across turns

Indicators:
- altered definitions
- inconsistent references

Impact:
- high

## Failure Mode 2 — Reinterpretation
Description:
- symbol meaning is reinterpreted or expanded

Indicators:
- invented meaning
- narrative inflation

Impact:
- high

## Failure Mode 3 — Anchor Break
Description:
- symbol anchor fails to activate

Indicators:
- unstable meaning
- inconsistent behaviour

Impact:
- moderate

## Failure Mode 4 — Cross-Model Instability
Description:
- external models fail to preserve meaning

Indicators:
- inconsistent symbol behaviour
- CAR loop deviation

Impact:
- moderate

## Failure Mode 5 — Long-Form Drift
Description:
- symbol meaning degrades across extended sequences

Indicators:
- meaning variance
- drift under pressure

Impact:
- high

## Failure Mode 6 — Reproducibility Failure
Description:
- repeated symbol sequences produce different outputs

Indicators:
- variance > 0
- unstable benchmarks

Impact:
- critical
