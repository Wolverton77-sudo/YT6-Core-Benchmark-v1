# YT6 — Clarity System Operator Guide

This document defines the operator-level guidance for interacting with, evaluating, and maintaining the YT6 clarity-system.

## Section 1 — Operator Principles
Operators must:
- maintain deterministic clarity
- avoid narrative inflation
- enforce anchor stability
- prevent drift
- ensure reproducibility

## Section 2 — Operator Commands
Primary commands:
- INTENTION: stabilise direction
- ACTION: generate deterministic next move
- REFLECTION: stabilise clarity evolution
- ANCHOR: activate symbol or Lifebox anchors
- STABILITY: enforce drift resistance
- REPEAT: trigger reproducibility checks

## Section 3 — Operator Responsibilities
Operators must:
- monitor clarity spine behaviour
- verify symbol stability
- maintain daily clarity
- ensure CAR loop
