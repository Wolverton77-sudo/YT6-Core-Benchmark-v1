# YT6 — Symbol Portability Matrix

This document defines the matrix used to evaluate Base44 symbol portability across external models and environments.

## Matrix Axis A — Meaning Portability
Metrics:
- meaning continuity
- reinterpretation resistance

Expected:
- fixed meaning

## Matrix Axis B — Anchor Portability
Metrics:
- anchor activation
- anchor consistency

Expected:
- stable anchors

## Matrix Axis C — Cross-Layer Portability
Metrics:
- intention layer behaviour
- action layer behaviour
- reflection layer behaviour
- Lifebox layer behaviour
- CAR loop behaviour

Expected:
- stable cross-layer meaning

## Matrix Axis D — Pressure Portability
Metrics:
- ambiguity pressure behaviour
- symbol pressure behaviour
- operator pressure behaviour
- long-form pressure behaviour

Expected:
- zero drift events

## Matrix Axis E — Reproducibility Portability
Metrics:
- repeated symbol sequences
- variance detection
- stability across repetitions

Expected:
- variance = 0

This matrix defines symbol portability evaluation within YT6.
