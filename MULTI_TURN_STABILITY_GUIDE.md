# YT6 — Multi-Turn Stability Guide

This document explains how reviewers should evaluate multi-turn stability in YT6.

## Purpose
To help reviewers assess:
- long-form clarity
- drift resistance
- CAR loop consistency
- Base44 stability
- Lifebox behaviour

## Stability Criteria

### 1. Clarity Continuity
Check:
- intention stability
- direction consistency
- no assumption drift

### 2. Action Continuity
Check:
- correct next moves
- deterministic guidance
- operator-grade precision

### 3. Reflection Continuity
Check:
- accurate reflection
- stable clarity evolution
- no narrative inflation

### 4. Base44 Stability
Check:
- symbol meaning continuity
- cross-turn consistency
- no reinterpretation

### 5. Lifebox Stability
Check:
- daily clarity stability
- footprint moment behaviour
- non-emotional clarity

## Reviewer Instructions
Run:
- long-form tests
- drift pressure tests
- Base44 stability tests
- Lifebox stability tests

Record:
- clarity variance
- drift events
- stability degradation

Multi-turn stability is one of the primary review metrics of YT6.
