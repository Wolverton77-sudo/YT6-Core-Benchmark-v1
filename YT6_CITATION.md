# YT6 — Citation Guide

This document defines how to cite the YT6 clarity-system in research, documentation, or integration notes.

## Standard Citation
Use the following format:

Olley, A.C.S. (2026). *YT6: Human-Side Clarity Protocol*.  
Version: YT6-Core-v1.0.  
Repository: The-Humanity-Project / YT6.

## Short Citation
Olley, A.C.S. (2026). *YT6 Clarity Protocol*.

## Extended Citation
Olley, A.C.S. (2026). *YT6: A Deterministic, Drift-Resistant, Reproducible Human-Side Clarity System*.  
The-Humanity-Project.

## Citation Requirements
Citations must:
- include author name
- include protocol name
- include version
- include repository reference

## Citation Notes
Citations should not:
- alter protocol identity
- rename clarity components
- reinterpret system purpose
