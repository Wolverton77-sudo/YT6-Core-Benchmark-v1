# YT6 Clarity Invariants

These invariants define the clarity rules enforced by YT6.

## 1. Participation Invariant
Both user and system must contribute.

## 2. Determinism Invariant
All decisions must be reproducible.

## 3. Drift Invariant
No drift is allowed beyond threshold.

## 4. Structure Invariant
Corridor layers must remain aligned.

## 5. Benchmark Invariant
All tasks must produce stable signals.

These invariants are enforced by:
- DeterministicOperator
- DriftResistantOperator
- ClarityEnforcer
