# YT6 Evaluator FastPath

This is the guide used by evaluators to quickly assess the repo.

## 1. README
Check clarity, structure, purpose.

## 2. Corridor
Verify Field → Frame → Fieldframe → Prime → Primeframe.

## 3. Operators
Check deterministic, drift, clarity enforcement.

## 4. Benchmark
Run tasks, inspect snapshot.md.

## 5. Eval
Check benchmark.md, reproduction.md, clarity-corridor.md.

## 6. Evidence
Verify stability, invariants, reproduction.

## 7. Decision
If all layers are stable → PASS.
