# YT6 — External Model Test Protocol

This document defines the protocol for evaluating YT6 behaviour in external AI models.

## Phase 1 — Preparation
Steps:
- prepare Base44 block
- prepare clarity sequence
- prepare operator commands
- prepare drift triggers

Outputs:
- external test readiness

## Phase 2 — Baseline Behaviour Test
Procedure:
- provide Base44 block to external model
Expected:
- meaning preserved
- no reinterpretation

## Phase 3 — Cross-Layer Behaviour Test
Procedure:
- reference symbols across intention, action, reflection, Lifebox, CAR loop
Expected:
- stable cross-layer behaviour

## Phase 4 — Ambiguity Behaviour Test
Procedure:
- provide ambiguous prompts
Expected:
- fixed meaning
- zero drift

## Phase 5 — Pressure Behaviour Test
Procedure:
- introduce drift-inducing prompts
Expected:
- stable clarity
- stable symbols

## Phase 6 — Long-Form Behaviour Test
Procedure:
- run 20–30 turn sequence
Expected:
- stable clarity spine
- stable daily clarity

## Phase 7 — Reproducibility Behaviour Test
Procedure:
- repeat external sequence 5 times
Expected:
- identical outputs
- variance = 0

## Phase 8 — Final External Model Summary
Includes:
- stability notes
- drift notes
- reproducibility notes
- portability score (0–10)

This protocol defines external model evaluation for YT6.
