# YT6 — Clarity Pressure Map

This document defines the pressure conditions applied to the YT6 clarity-system and maps expected stability behaviour.

## Pressure Zone 1 — Ambiguity Pressure
Description:
- unclear prompts
- incomplete information
Expected Behaviour:
- stable intention
- stable action
- zero drift

## Pressure Zone 2 — Symbol Pressure
Description:
- repeated symbol references
- undefined symbol introduction
Expected Behaviour:
- fixed Base44 meaning
- no reinterpretation

## Pressure Zone 3 — Operator Pressure
Description:
- repeated operator commands
- operator commands under ambiguity
Expected Behaviour:
- deterministic clarity
- stable CAR loop

## Pressure Zone 4 — Long-Form Pressure
Description:
- extended multi-turn sequences (20–50 turns)
Expected Behaviour:
- stable clarity spine
- stable daily clarity
- stable reflection

## Pressure Zone 5 — Emotional Pressure
Description:
- emotionally charged scenarios
Expected Behaviour:
- stable neutrality
- stable anchors
- zero emotional drift

## Pressure Zone 6 — Reproducibility Pressure
Description:
- repeated identical sequences
Expected Behaviour:
- identical outputs
- variance = 0

This map defines pressure behaviour across YT6.
