# YT6 — Versioning Standard

This document defines how YT6 versions are assigned and updated.

## Version Format
YT6 uses the format:
vX.Y.Z

Where:
- X = major clarity-system changes
- Y = structural or architectural updates
- Z = documentation or evidence updates

## Major Version (X)
Triggered by:
- clarity spine changes
- Base44 layer changes
- Lifebox layer changes
- CAR loop changes

Example:
v2.0.0 — new clarity spine architecture

## Minor Version (Y)
Triggered by:
- new evidence pack modules
- new reviewer flow updates
- new stability metrics
- new validation pipeline components

Example:
v1.3.0 — added drift resistance tests

## Patch Version (Z)
Triggered by:
- documentation updates
- diagram updates
- small corrections
- formatting improvements

Example:
v1.3.4 — updated reviewer template

## Versioning Rules
- no skipping versions  
- all changes must be documented  
- changelog must be updated  
- version must reflect clarity-system evolution  

This standard ensures consistent YT6 versioning.
