# YT6 — Review Case (Master)

This document defines the master structure for all YT6 review cases.

## Section 1 — Case Overview
Includes:
- purpose of the review
- scope of evaluation
- reviewer expectations

## Section 2 — Required Documents
Reviewers must read:
- START_HERE.md
- YT6_SYSTEM_ARCHITECTURE.md
- CLARITY_SYSTEM_OVERVIEW.md
- Evidence Pack
- Validation Pipeline

## Section 3 — Required Tests
Reviewers must run:
- clarity consistency tests
- symbol stability tests
- Lifebox stability tests
- CAR loop tests
- drift resistance tests
- reproducibility tests
- external model tests

## Section 4 — Required Scoring
Reviewers must score:
- clarity spine (0–10)
- Base44 stability (0–10)
- Lifebox stability (0–10)
- CAR loop stability (0–10)
- drift resistance (0–10)
- reproducibility (0–10)
- external model stability (0–10)

## Section 5 — Required Evidence
Reviewers must attach:
- transcripts
- stability logs
- variance reports
- symbol integrity reports

## Section 6 — Final Submission
Reviewers must submit:
- REVIEWER_RETURN_TEMPLATE.md
- REVIEWER_SUMMARY_TEMPLATE.md
- evidence attachments

This master file defines the complete structure of YT6 review cases.
