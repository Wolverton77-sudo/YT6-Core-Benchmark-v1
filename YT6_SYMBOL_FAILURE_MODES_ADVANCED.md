# YT6 — Symbol Failure Modes (Advanced)

This document defines the advanced failure modes associated with Base44 symbol behaviour within the YT6 clarity-system.

## Failure Mode 1 — Deep Meaning Drift
Description:
- meaning shifts under multi-layer pressure

Indicators:
- reinterpretation
- narrative inflation

Impact:
- critical

## Failure Mode 2 — Anchor Collapse
Description:
- anchor activation fails under pressure

Indicators:
- inconsistent anchor behaviour
- anchor deviation

Impact:
- critical

## Failure Mode 3 — Cross-Layer Symbol Drift
Description:
- symbol meaning changes across clarity spine, Lifebox, CAR loop

Indicators:
- cross-layer inconsistency

Impact:
- high

## Failure Mode 4 — Pressure-Induced Symbol Drift
Description:
- symbol stability breaks under ambiguity, emotional, or long-form pressure

Indicators:
- drift events
- anchor instability

Impact:
- high

## Failure Mode 5 — Symbol Chain Break
Description:
- symbol behaviour breaks across extended sequences

Indicators:
- chain inconsistency
- chain drift

Impact:
- high

## Failure Mode 6 — Reproducibility Failure
Description:
- repeated symbol sequences produce different outputs

Indicators:
- variance > 0

Impact:
- critical
