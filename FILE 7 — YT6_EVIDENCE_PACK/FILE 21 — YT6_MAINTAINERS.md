# YT6 Maintainers Guide

This file defines the responsibilities and expectations for maintainers of the YT6 clarity-layer protocol.

## Maintainer Responsibilities
1. **Preserve Clarity-Layer Integrity**  
   All changes must maintain deterministic structure and stable reasoning.

2. **Prevent Drift Introduction**  
   No update may weaken drift-resistance.

3. **Ensure Reproducibility**  
   All behaviour must remain testable and repeatable.

4. **Maintain Documentation Quality**  
   Documentation must remain clear, complete and publicly understandable.

5. **Validate Evidence**  
   Logs, traces and benchmark results must be updated with each change.

6. **Review Contributions**  
   All pull requests must follow the YT6 contribution rules.

## Maintainer Requirements
- Understanding of clarity-layer principles  
- Familiarity with stability and drift-resistance rules  
- Ability to evaluate reproducibility  
- Commitment to evidence-based development  

## Maintainer Code
- Clarity first  
- Stability preserved  
- Drift-resistance enforced  
- Reproducibility required  
- Transparency maintained  

Maintainers ensure YT6 remains a world-class clarity-layer protocol.
