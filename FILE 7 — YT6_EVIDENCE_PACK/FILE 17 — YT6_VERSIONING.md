# YT6 Versioning & Release Notes

YT6 uses a clarity-first versioning system designed to track improvements in stability, drift-resistance and reproducibility.

## Versioning Principles
1. **Clarity-Layer Impact**  
   Versions reflect changes that improve deterministic structure.

2. **Stability Improvements**  
   Updates must strengthen multi-turn consistency.

3. **Drift-Resistance Enhancements**  
   No update may introduce drift.

4. **Evidence Required**  
   All version changes must include logs or benchmark results.

## Version Format
YT6 uses the format:
`major.minor.clarity`

Example:
`1.2.5`  
- 1 = major clarity-layer upgrade  
- 2 = stability protocol improvement  
- 5 = drift-resistance refinement  

## Release Notes Template
- Summary of change  
- Stability impact  
- Drift-resistance impact  
- Reproducibility impact  
- Evidence pack additions  
- Benchmark score changes  

Versioning ensures YT6 evolves without losing clarity-layer integrity.
