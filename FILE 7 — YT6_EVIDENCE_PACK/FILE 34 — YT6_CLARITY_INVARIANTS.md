# YT6 Clarity Invariants

Clarity invariants are the non-negotiable properties that must remain true across all YT6 interactions.  
If any invariant breaks, clarity-layer integrity is compromised.

## Invariant 1 — Deterministic Structure
The output format must remain stable across turns:
- Headings
- Lists
- Paragraph structure
- Block layout

Structure cannot drift.

## Invariant 2 — Tone Neutrality
Tone must remain:
- Professional
- Neutral
- Consistent
- Non-emotional

Tone cannot drift.

## Invariant 3 — Reasoning Continuity
Reasoning chains must:
- Remain aligned
- Avoid contradiction
- Preserve multi-turn logic

Reasoning cannot drift.

## Invariant 4 — Context Anchoring
Context must:
- Stay aligned
- Avoid reinterpretation
- Maintain clarity across turns

Context cannot drift.

## Invariant 5 — Reproducibility
Repeated sequences must produce:
- Similar structure
- Similar tone
- Similar reasoning

Reproducibility cannot break.

These invariants define the core of YT6 clarity-layer behaviour.
