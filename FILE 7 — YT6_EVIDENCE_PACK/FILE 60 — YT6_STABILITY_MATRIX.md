# YT6 Stability Matrix

The Stability Matrix defines the structured evaluation model used to measure clarity-layer stability across multiple dimensions.

## Matrix Overview
The matrix evaluates stability across five dimensions:

- Structure  
- Tone  
- Reasoning  
- Context  
- Reproducibility  

Each dimension contributes to the total stability score.

## Dimension 1 — Structural Dimension
Measures:
- Formatting consistency
- Deterministic layout

Weight:
20%

## Dimension 2 — Tone Dimension
Measures:
- Neutral tone
- Professional consistency

Weight:
20%

## Dimension 3 — Reasoning Dimension
Measures:
- Logical continuity
- Multi-turn coherence

Weight:
20%

## Dimension 4 — Context Dimension
Measures:
- Stable interpretation
- No drift in meaning

Weight:
20%

## Dimension 5 — Reproducibility Dimension
Measures:
- Session-to-session similarity
- Repeatable behaviour

Weight:
20%

## Total Stability Matrix Score (0–100)
Interpretation:
- **76–100**: Fully stable  
- **51–75**: Mostly stable  
- **26–50**: Partially stable  
- **0–25**: Unstable  

The Stability Matrix provides a complete, weighted stability evaluation model.
