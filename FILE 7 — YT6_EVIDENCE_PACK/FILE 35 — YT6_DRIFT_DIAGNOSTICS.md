# YT6 Drift Diagnostics

This file defines diagnostic procedures for detecting drift in multi-turn AI interactions.

## Diagnostic 1 — Tone Drift Scan
Procedure:
- Compare tone across turns
- Detect emotional shifts
- Identify personality changes

Indicators:
- Increased enthusiasm
- Sudden informality
- Emotional colouring

YT6 Countermeasure:
Tone locking.

## Diagnostic 2 — Structural Drift Scan
Procedure:
- Compare formatting across turns
- Detect layout divergence
- Identify block instability

Indicators:
- Missing headings
- Irregular lists
- Paragraph fragmentation

YT6 Countermeasure:
Deterministic structure.

## Diagnostic 3 — Reasoning Drift Scan
Procedure:
- Track logical chains
- Detect contradictions
- Identify reasoning divergence

Indicators:
- Changing conclusions
- Reinterpreted context
- Fragmented logic

YT6 Countermeasure:
Reasoning continuity rules.

## Diagnostic 4 — Context Drift Scan
Procedure:
- Compare context interpretation
- Detect misalignment
- Identify reinterpretation

Indicators:
- Forgotten constraints
- Shifted goals
- Misread instructions

YT6 Countermeasure:
Context anchoring.

## Diagnostic 5 — Output Drift Scan
Procedure:
- Compare density and clarity
- Detect verbosity changes
- Identify style divergence

Indicators:
- Sudden minimalism
- Sudden verbosity
- Unpredictable formatting

YT6 Countermeasure:
Clarity-layer invariants.

These diagnostics support benchmark scoring and evidence analysis.
