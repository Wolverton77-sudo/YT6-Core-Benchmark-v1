# YT6 Style Guide

This guide defines the writing style used across the YT6 clarity-layer project.

## Structural Rules
- Use headings and subheadings
- Use short, direct paragraphs
- Use bullet lists for clarity
- Maintain deterministic formatting

## Tone Rules
- Neutral
- Professional
- Consistent
- No emotional drift

## Language Rules
- Avoid vague terms
- Use precise clarity-layer terminology
- Define all technical concepts
- Maintain reproducibility in examples

## Formatting Rules
- Use code blocks for structured examples
- Use bold for emphasis sparingly
- Avoid unnecessary decoration
