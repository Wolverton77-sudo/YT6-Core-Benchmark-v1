# YT6 Clarity Operators

Clarity operators are the activation signals and structural commands that initiate and maintain YT6 clarity-layer behaviour.

## Operator 1 — yt>
Purpose:
- Activate clarity-layer mode
- Enforce deterministic structure
- Lock tone and reasoning

Usage:
yt> next 3  
yt> run stability  
yt> clarity test

## Operator 2 — yt.stable>
Purpose:
- Reinforce stability fields
- Re-lock tone, structure and reasoning

Usage:
yt.stable> verify  
yt.stable> align

## Operator 3 — yt.check>
Purpose:
- Run diagnostics
- Scan for drift signals

Usage:
yt.check> drift  
yt.check> structure  
yt.check> tone

## Operator 4 — yt.proof>
Purpose:
- Validate clarity invariants
- Confirm reproducibility

Usage:
yt.proof> invariants  
yt.proof> reproduce

## Operator 5 — yt.map>
Purpose:
- Display clarity-layer relationships
- Show conceptual structure

Usage:
yt.map> clarity  
yt.map> drift

Clarity operators form the command surface of the YT6 protocol.
