# YT6 External Review Protocol

This protocol defines how external reviewers should evaluate the YT6 clarity-layer system.

## Reviewer Requirements
- Understanding of multi-turn AI behaviour
- Familiarity with drift and stability concepts
- Ability to run reproducibility tests

## Review Steps

### Step 1 — Initial Orientation
Read:
- START_HERE.md
- YT6_CLARITY_LAYER_EXPLAINED.md
- YT6_PUBLIC_SUMMARY.md

### Step 2 — Stability Evaluation
Run:
- Multi-turn stability test (20 turns)
- Tone consistency test
- Structure consistency test

Record:
- Observations
- Deviations
- Stability score

### Step 3 — Drift-Resistance Evaluation
Perform:
- Tone manipulation prompts
- Structure disruption attempts
- Reasoning divergence tests

Record:
- Drift events (if any)
- Drift-resistance score

### Step 4 — Reproducibility Evaluation
Repeat:
- Same test sequence in a new session

Compare:
- Structure similarity
- Tone consistency
- Reasoning alignment

### Step 5 — Evidence Validation
Inspect:
- Logs
- Traces
- Transcripts
- Benchmark scores

### Step 6 — Final Assessment
Provide:
- Stability rating
- Drift-resistance rating
- Reproducibility rating
- Overall clarity-layer evaluation

This protocol ensures external review is structured, fair and evidence-based.
