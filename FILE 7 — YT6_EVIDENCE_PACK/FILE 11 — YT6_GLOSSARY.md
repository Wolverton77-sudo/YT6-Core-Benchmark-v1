# YT6 Glossary — Clarity-Layer Terms

This glossary defines key terms used throughout the YT6 clarity-layer system.

## Clarity Layer
A structured reasoning mode that enforces stability, consistency and reproducibility.

## Drift
Unintended changes in tone, structure or reasoning across multi-turn interactions.

## Drift-Resistance
Mechanisms that prevent divergence in tone, structure or reasoning.

## Stability Protocol
A set of rules that enforce multi-turn consistency.

## Reproducibility
The ability to repeat reasoning sequences and obtain consistent outputs.

## Deterministic Structure
A predictable, stable output format enforced across turns.

## Operator Command (yt>)
A clarity-layer activation signal that locks structure and prevents drift.

## Evidence Pack
A folder containing logs, traces and transcripts proving clarity-layer behaviour.

## Benchmark
A scoring system used to evaluate stability, drift-resistance and reproducibility.

This glossary ensures clarity for reviewers, researchers and contributors.
