# YT6 Stability Grid

The Stability Grid defines the multi-dimensional matrix used to evaluate clarity-layer stability across all axes.

## Grid Overview
The grid evaluates stability across five axes:

- Structure  
- Tone  
- Reasoning  
- Context  
- Reproducibility  

Each axis contributes to the total stability score.

## Axis 1 — Structural Axis
Measures:
- Formatting consistency
- Deterministic layout

Score Range:
0–20

## Axis 2 — Tone Axis
Measures:
- Neutral tone
- Professional consistency

Score Range:
0–20

## Axis 3 — Reasoning Axis
Measures:
- Logical continuity
- Multi-turn coherence

Score Range:
0–20

## Axis 4 — Context Axis
Measures:
- Stable interpretation
- No drift in meaning

Score Range:
0–20

## Axis 5 — Reproducibility Axis
Measures:
- Session-to-session similarity
- Repeatable behaviour

Score Range:
0–20

## Total Stability Grid Score (0–100)
Interpretation:
- **76–100**: Fully stable  
- **51–75**: Mostly stable  
- **26–50**: Partially stable  
- **0–25**: Unstable  

The Stability Grid provides a complete stability evaluation model.
