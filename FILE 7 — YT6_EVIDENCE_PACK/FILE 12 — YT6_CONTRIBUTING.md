# Contributing to YT6

YT6 is designed as a clarity-layer protocol that benefits from structured contributions.  
This file explains how contributors can add to the project while maintaining clarity-layer standards.

## Contribution Principles
1. **Clarity First**  
   All contributions must preserve deterministic structure and clarity-layer alignment.

2. **Stability Preservation**  
   No changes may introduce drift or multi-turn instability.

3. **Reproducibility Required**  
   All additions must be testable and repeatable.

4. **Evidence-Based Changes**  
   Contributions must include logs, traces or benchmark results when relevant.

## How to Contribute
1. Review START_HERE.md  
2. Read the clarity-layer explanation  
3. Follow stability and drift-resistance rules  
4. Add tests to the reproduction guide  
5. Update the benchmark if needed  
6. Provide evidence in the evidence pack  

## Pull Request Requirements
- Clear description  
- Stability impact analysis  
- Drift-resistance verification  
- Reproduction tests  
- Benchmark scoring  

YT6 contributions must strengthen clarity, not weaken it.
