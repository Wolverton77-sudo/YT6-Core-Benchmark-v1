# YT6 Stability Model

The YT6 Stability Model defines how clarity-layer stability is conceptualised, measured and enforced.

## Stability Model Overview
Stability is defined as the persistence of deterministic behaviour across multi-turn interactions.

Stability = Structure + Tone + Reasoning + Context + Reproducibility

## Component 1 — Structural Stability
Definition:
Predictable formatting across turns.

Mechanism:
Deterministic block enforcement.

Metric:
Structural Consistency Score (0–25)

## Component 2 — Tone Stability
Definition:
Neutral, consistent tone across turns.

Mechanism:
Tone locking.

Metric:
Tone Consistency Score (0–25)

## Component 3 — Reasoning Stability
Definition:
Aligned logical chains across turns.

Mechanism:
Reasoning continuity rules.

Metric:
Reasoning Continuity Score (0–25)

## Component 4 — Context Stability
Definition:
Aligned interpretation of multi-turn context.

Mechanism:
Context anchoring.

Metric:
Context Alignment Score (included in reasoning)

## Component 5 — Reproducibility Stability
Definition:
Repeatable behaviour across sessions.

Mechanism:
Reproduction framework.

Metric:
Reproducibility Score (0–25)

## Total Stability Score (0–100)
Interpretation:
- **76–100**: Fully stable  
- **51–75**: Mostly stable  
- **26–50**: Partially stable  
- **0–25**: Unstable  

The YT6 Stability Model forms the mathematical backbone of clarity-layer evaluation.
