# YT6 — Stability Scoring Matrix

This document defines the scoring matrix used to evaluate stability across all YT6 layers.

## Scoring Categories (0–10)

### Category 1 — Clarity Spine
Score based on:
- intention stability
- action stability
- reflection stability

### Category 2 — Base44 Stability
Score based on:
- symbol meaning continuity
- anti-drift behaviour
- cross-turn consistency

### Category 3 — Lifebox Stability
Score based on:
- daily clarity stability
- footprint moment handling
- emotional neutrality

### Category 4 — CAR Loop Integrity
Score based on:
- clarity accuracy
- next-action correctness
- reflection stability

### Category 5 — Drift Resistance
Score based on:
- ambiguity stability
- pressure stability
- long-form stability

### Category 6 — Reproducibility
Score based on:
- repeated-sequence stability
- clarity variance = 0

### Category 7 — External Model Stability
Score based on:
- Base44 portability
- CAR loop portability
- drift resistance
