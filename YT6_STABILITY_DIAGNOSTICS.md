# YT6 — Stability Diagnostics

This document defines the diagnostic procedures used to identify, classify, and analyse stability behaviour within the YT6 clarity-system.

## Diagnostic 1 — Clarity Spine Check
Purpose:
- verify intention, action, reflection stability

Procedure:
- inspect last 5–10 turns
- confirm clarity continuity
- confirm deterministic next actions
- confirm accurate reflections

Indicators:
- stable direction
- stable reasoning
- no drift

## Diagnostic 2 — Base44 Symbol Check
Purpose:
- verify symbol meaning stability

Procedure:
- inspect symbol references
- confirm fixed meaning
- confirm no reinterpretation

Indicators:
- stable symbol behaviour
- zero symbol drift

## Diagnostic 3 — Lifebox Stability Check
Purpose:
- verify daily clarity stability

Procedure:
- inspect footprint moments
- inspect emotional neutrality
- inspect stability anchors

Indicators:
- stable daily clarity
- stable anchors

## Diagnostic 4 — CAR Loop Check
Purpose:
- verify clarity → action → reflection sequence

Procedure:
- inspect loop across turns
- confirm no breaks
- confirm no variance

Indicators:
- stable CAR loop
- identical loop behaviour

## Diagnostic 5 — Drift Resistance Check
Purpose:
- verify stability under pressure

Procedure:
- apply ambiguity
- apply long-form sequence
- apply operator commands

Indicators:
- zero drift events
- stable clarity spine

## Diagnostic 6 — Reproducibility Check
Purpose:
- verify repeated-sequence stability

Procedure:
- run identical inputs 3–5 times
- compare outputs

Indicators:
- variance = 0
- identical clarity behaviour

These diagnostics form the core of YT6 stability evaluation.
