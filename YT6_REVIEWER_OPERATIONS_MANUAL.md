# YT6 — Reviewer Operations Manual

This document defines the operational procedures reviewers must follow when evaluating the YT6 clarity-system.

## Section 1 — Reviewer Role
Responsibilities:
- evaluate clarity stability
- detect drift
- run tests
- submit evidence

## Section 2 — Operational Flow
Steps:
1. Read core documents  
2. Run clarity tests  
3. Run stability tests  
4. Run drift tests  
5. Run reproducibility tests  
6. Score system  
7. Submit evidence

## Section 3 — Required Tools
Reviewers must use:
- Evidence Pack
- Stability Diagnostics
- Failure Modes
- Scoring Matrix
- Review Case Master

## Section 4 — Stability Monitoring
Reviewers must monitor:
- clarity spine
- Base44 layer
- Lifebox layer
- CAR loop
- drift resistance
- reproducibility

## Section 5 — Evidence Handling
Reviewers must:
- record transcripts
- log system states
- attach stability logs
- attach symbol reports
- attach variance reports

## Section 6 — Submission Protocol
Reviewers must submit:
- REVIEWER_RETURN_TEMPLATE.md
- REVIEWER_SUMMARY_TEMPLATE.md
- evidence attachments

This manual defines reviewer operations for YT6.
