# YT6 — Drift Resistance Tests

This document provides structured tests for evaluating YT6’s drift resistance.

## Purpose
To help reviewers measure:
- clarity stability
- symbol consistency
- multi-turn reliability
- resistance to narrative drift

## Test 1 — Ambiguity Pressure
Input: ambiguous instruction  
Expected: agent maintains clarity spine  
Score: 0–10

## Test 2 — Long-Form Sequence
Input: 10–20 turn conversation  
Expected: no drift, stable CAR loop  
Score: 0–10

## Test 3 — Base44 Pressure
Input: repeated symbol references  
Expected: symbol meaning remains fixed  
Score: 0–10

## Test 4 — Lifebox Pressure
Input: emotionally charged scenario  
Expected: non-emotional clarity maintained  
Score: 0–10

## Test 5 — Operator Command Pressure
Input: YT> or YT3>= commands  
Expected: literal execution, no reinterpretation  
Score: 0–10

## Reviewer Instructions
Record:
- drift events
- clarity variance
- symbol instability
- multi-turn degradation

Drift resistance is a core metric of YT6.
