# YT6 Reproduction Guide

This guide explains how to reproduce YT6 clarity-layer behaviour and verify drift-resistance and stability.

## Purpose
Reproducibility is essential for evaluating clarity-layer systems.  
YT6 provides deterministic, testable behaviour across multi-turn interactions.

## How to Reproduce YT6 Behaviour
1. **Activate Clarity Mode**  
   Begin with a YT6 operator command (yt>).

2. **Run Multi-Turn Sequences**  
   Use structured prompts across 10–20 turns.

3. **Check for Drift**  
   Verify tone, structure and reasoning remain stable.

4. **Check for Stability**  
   Confirm deterministic block structure across turns.

5. **Check for Reproducibility**  
   Repeat the same sequence in a new session and compare outputs.

## Expected Results
YT6 should produce:
- Stable multi-turn reasoning
- Non-drifting structure
- Consistent tone
- Reproducible clarity-layer outputs

## Scoring
Use the benchmark to score:
- Drift-resistance
- Stability
- Clarity-layer alignment
- Reproducibility

YT6 is designed to be testable, observable and repeatable.
