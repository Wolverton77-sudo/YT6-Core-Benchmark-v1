# YT6 — Failure Modes (Tier‑7)

Failure Modes define how YT6 detects, reports, and contains clarity failures.

---

## 1. Purpose
Failure mode analysis ensures:
- clarity failures are predictable  
- drift is contained  
- ambiguity is controlled  
- stability is restored  
- system behaviour remains safe  

---

## 2. Failure Mode Categories

### 1. Drift Failure
Meaning or intention shifts unexpectedly.

### 2. Ambiguity Failure
Agent invents meaning instead of marking ambiguity.

### 3. Stability Failure
Clarity spine collapses or structure mutates.

### 4. Continuity Failure
Intention, constraints, or context break.

### 5. Load Failure
Clarity collapses under pressure or speed.
