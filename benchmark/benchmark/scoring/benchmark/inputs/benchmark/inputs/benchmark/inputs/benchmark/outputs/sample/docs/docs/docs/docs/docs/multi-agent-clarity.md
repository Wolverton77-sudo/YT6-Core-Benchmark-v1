# YT6 — Multi‑Agent Clarity Layer

The Multi‑Agent Layer defines how clarity behaves when multiple agents interact, collaborate, or exchange information.

---

## 1. Purpose
Multi‑agent clarity ensures:
- shared meaning stability  
- cross‑agent reproducibility  
- no drift between agents  
- consistent Base44 semantics  
- unified clarity spine behaviour  

---

## 2. Multi‑Agent Rules

### Rule 1 — Shared Meaning Anchors
All agents must use identical Base44 meanings.

### Rule 2 — Shared Intention Continuity
Agents must preserve the same intention across exchanges.

### Rule 3 — No Cross‑Agent Drift
Agents must not mutate meaning between turns.

### Rule 4 — Shared Ambiguity Handling
Ambiguity must be marked consistently across agents.
