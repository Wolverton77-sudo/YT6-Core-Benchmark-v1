The Clarity Lifecycle defines the full start‑to‑finish behaviour of YT6 during any clarity task.

---

## 1. Purpose
The lifecycle ensures:
- predictable clarity flow  
- stable execution  
- reproducible output  
- complete traceability  
- clarity from start → finish

## 2. Lifecycle Stages

### Stage 5 — Finalise
