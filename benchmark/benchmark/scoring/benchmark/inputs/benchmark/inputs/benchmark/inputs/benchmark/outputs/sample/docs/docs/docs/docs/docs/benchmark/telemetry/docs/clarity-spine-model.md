# YT6 — Clarity Spine Model (Tier‑4)

The Clarity Spine is the core behavioural model of YT6.  
It defines how clarity flows through every agent turn.

---

## 1. Purpose
The spine ensures:
- structural clarity  
- behavioural stability  
- reproducibility  
- drift‑resistance  
- multi‑turn consistency  

---

## 2. The Three Spine Segments

### Segment 1 — Clarity
The agent establishes:
- intention  
- constraints  
- missing information  
- Base44 meaning locks  

### Segment 2 — Action
The agent performs:
- stable execution  
- clarity‑aligned behaviour  
- drift‑resistant output  

### Segment 3 — Reflection
The agent reports:
- what stayed stable  
- what changed  
- ambiguity status  
- drift status
