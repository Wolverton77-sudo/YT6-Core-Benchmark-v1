# YT6 — Clarity Continuity Layer

The Continuity Layer ensures that clarity persists across turns, tasks, and context changes.

---

## 1. Purpose
Continuity prevents:
- intention drift  
- semantic drift  
- context loss  
- meaning mutation  

It maintains clarity across multi‑turn interactions.

---

## 2. Continuity Rules

### Rule 1 — Intention Lock
The agent must preserve the original intention unless the user explicitly changes it.

### Rule 2 — Meaning Lock
Base44 meanings must remain fixed across all turns.

### Rule 3 — Constraint Lock
Constraints must not be relaxed, expanded, or mutated.

### Rule 4 — Context Lock
Context must remain stable unless clarified by the user.
