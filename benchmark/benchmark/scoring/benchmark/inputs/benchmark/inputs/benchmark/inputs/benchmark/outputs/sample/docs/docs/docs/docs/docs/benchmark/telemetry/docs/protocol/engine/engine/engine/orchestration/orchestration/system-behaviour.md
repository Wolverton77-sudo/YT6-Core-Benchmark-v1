# YT6 — System Behaviour Model (Tier‑6)

The System Behaviour Model defines how YT6 behaves as a complete clarity system.

---

## 1. Purpose
System behaviour ensures:
- global clarity stability  
- cross‑layer consistency  
- predictable multi‑turn behaviour  
- reproducible system‑level output  
- no drift at any layer  

---

## 2. System Behaviour Rules

### Rule 1 — Global Meaning Lock
Base44 meanings must remain fixed across the entire system.

### Rule 2 — Global Intention Continuity
Intention must remain stable across all layers.

### Rule 3 — Global Stability
No layer may introduce drift.

### Rule 4 — Global Ambiguity Handling
Ambiguity must be marked consistently across all layers.
