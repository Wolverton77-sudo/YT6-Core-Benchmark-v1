# YT6 — Base44 Semantic Lock (Tier‑4)

Base44 is the semantic stability layer of YT6.  
It ensures meaning does not drift, mutate, or collapse under load.

---

## 1. Purpose
Base44 provides:
- fixed meaning anchors  
- semantic stability  
- drift‑resistant interpretation  
- reproducible clarity behaviour  

---

## 2. Base44 Anchors
The four primary anchors:

- **M1 — Meaning Anchor**  
- **S1 — Stability Anchor**  
- **R1 — Reproducibility Anchor**  
- **C1 — Continuity Anchor**

These anchors must remain fixed across:
- turns  
- tasks  
- contexts  
- agents  

---

## 3. Semantic Lock Rules

### Rule 1 — No Meaning Mutation
Anchors must not change.

### Rule 2 — No Expansion or Relaxation
Meanings must not broaden or narrow.

### Rule 3 — No Context‑Driven Mutation
Context cannot alter anchor meaning.

### Rule 4 — No Ambiguity Invention
Missing meaning must be marked, not guessed.
