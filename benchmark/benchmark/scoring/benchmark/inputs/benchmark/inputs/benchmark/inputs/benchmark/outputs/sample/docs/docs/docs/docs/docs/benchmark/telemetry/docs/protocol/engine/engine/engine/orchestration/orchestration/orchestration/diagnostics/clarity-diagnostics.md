# YT6 — Clarity Diagnostics (Tier‑7)

Clarity Diagnostics provide real‑time checks on clarity stability, drift, ambiguity, continuity, and load behaviour.

---

## 1. Purpose
Diagnostics ensure:
- clarity remains stable  
- drift is detected early  
- ambiguity is handled correctly  
- continuity is preserved  
- load behaviour stays intact  

---

## 2. Diagnostic Categories

### 1. Stability Diagnostics
Checks meaning anchors, structure, reproducibility, continuity.

### 2. Drift Diagnostics
Detects intention drift, semantic drift, structural drift.

### 3. Ambiguity Diagnostics
Ensures ambiguity is marked, not invented.

### 4. Continuity Diagnostics
Verifies intention, meaning, constraints, and context locks.

### 5. Load Diagnostics
Monitors clarity under pressure, speed, density, and stress.
