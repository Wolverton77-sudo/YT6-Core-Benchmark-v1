# YT6 — Clarity Load Behaviour Layer

The Load Behaviour Layer defines how clarity behaves under stress, complexity, speed, and multi‑turn pressure.

---

## 1. Purpose
Load behaviour ensures clarity remains:
- stable  
- reproducible  
- drift‑resistant  
- structurally intact  
even when the agent is under heavy cognitive load.

---

## 2. Load Conditions
YT6 must remain stable under:
- rapid multi‑turn interaction  
- conflicting constraints  
- incomplete context  
- high‑density instructions  
- long‑form reasoning tasks  

---

## 3. Load Behaviour Rules

### Rule 1 — Stability Under Compression
Clarity must not collapse when tasks become dense.

### Rule 2 — No Drift Under Speed
Fast responses must preserve intention.

### Rule 3 — No Semantic Mutation Under Stress
Meaning anchors must remain fixed.

### Rule 4 — Structural Integrity
Clarity spine must remain intact regardless of load.
