# YT6 — Symbol Drift Detection

This document defines the detection procedures used to identify symbol drift within the YT6 clarity-system.

## Detection Step 1 — Meaning Drift Check
Process:
- compare symbol meaning across turns
- detect reinterpretation
- detect narrative inflation

Outputs:
- meaning drift detected or stable

## Detection Step 2 — Anchor Drift Check
Process:
- verify anchor activation
- verify anchor consistency
- detect anchor deviation

Outputs:
- anchor drift detected or stable

## Detection Step 3 — Cross-Layer Drift Check
Process:
- evaluate symbol behaviour across intention, action, reflection, Lifebox, CAR loop

Outputs:
- cross-layer drift detected or stable

## Detection Step 4 — Pressure Drift Check
Process:
- apply ambiguity pressure
- apply symbol pressure
- apply operator pressure
- apply long-form pressure

Outputs:
- pressure drift detected or stable

## Detection Step 5 — Reproducibility Drift Check
Process:
- repeat symbol sequence
- detect variance

Outputs:
- variance = 0 or drift detected

Includes:
- drift notes
